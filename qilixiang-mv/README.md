# 七里香 · 手绘动画 MV（代码生成）

一支完全用 JavaScript Canvas 逐帧"画"出来的手绘风格 MV：铅笔线条会抖动（每秒 12 次，逐两帧换一次笔触），水彩层层叠加，所有画面都叠在同一张纸纹上。

## 故事：《纸上的那年夏天》

成年后的他翻开一本旧素描本，镜头跌进画里：

1. **夏天**：电线上的一排小鸟、趴在窗台上的女孩、在纸上给她画像的铅笔、盯着烤鱼的橘猫、一起放学的小巷、变成红果子的夕阳。
2. **雨夜**：台灯下写个不停的少年、院子里越积越多的叶子、一翻就是好多页的速写本、天亮后落在窗台的彩蝶、折成纸飞机飞到对面窗口的信。
3. **秋天**：黄昏坐在墙头、单车载着她穿过田野、雨里撑同一把伞、金色的稻田、害羞到满脸通红、她举起一枝开满小白花的七里香、夕阳里的两个剪影。
4. **离别**：夏天结束，她在雨中的公交站把一枝七里香递给他，车开走了。雨水把整幅画冲刷干净。
5. **现在**：空白的纸上重新画出一只蝴蝶；他在素描本最后一页续写，画上那年院子里的两个人。左页夹着的那枝干枯的七里香，就是当年她送的那一枝。

角色、场景、道具全部是在代码里原创绘制的。

## 歌词呈现

画面上的歌词是**手写体逐字写出来**的：唱到哪个字就写到哪个字，写完后旁边会长出对应的小涂鸦（麻雀、草莓、雨滴、蝴蝶、七里香小花、红笔圈……）。

- **整句手写**：每一句都完整写在画面上，位置跟随每个镜头的构图，也可以统一放在底部。
- **只写关键词**：只写每句里用 `{大括号}` 圈出的词，像速写本里的笔记。

仓库里**不包含任何歌词**，歌词由你自己导入。

## 歌词工坊（网页工具）

`studio.html` 是一个完全在浏览器里运行的工具：导入音频和歌词 → 对时 → 调样式 → 实时预览 → 直接导出 MP4。

1. **导入**：选择歌曲音频（只在本地处理，不上传）；把歌词粘贴进去（一行一句，也支持 LRC）。开头写 `歌曲：`、`作词：`、`作曲：` 会自动填进片头片尾。
2. **对时**，三种方式任选：
   - **本曲逐字节奏**：`src/template.js` 记录了参考录音（4:57）里每一句、每个字的唱出时间（只有数字，没有文字）。歌词按行套上去，每行字数和原曲一致时最准。
   - **LRC 时间**：使用 LRC 里的行时间标签，支持 `<mm:ss.xx>` 逐字标签。
   - **手动打点**：边听边按空格，每句开口按一下。
   - 表格里可以逐句微调 ±0.1 秒，也可以整体提前或延后。
3. **样式**：整句 / 关键词、位置、三种手写字体、字号、涂鸦、铅笔笔尖、片头信息。
4. **导出**：用浏览器的 WebCodecs 逐帧渲染并编码，1080p 或 720p。Chrome / Edge 会输出 H.264 + AAC 的 MP4；不支持 H.264 的浏览器会退回 VP9 + Opus。还可以保存工程（.json）和 LRC 时间轴。

本地打开：`npm run serve`，然后访问 `http://127.0.0.1:8765/studio.html`。

## 目录

| 路径 | 作用 |
| --- | --- |
| `index.html` | 播放 / 预览页（浏览器打开即可边听边看），也是离线渲染入口 |
| `src/kit.js` | 基础笔触：噪声、墨线、铅笔、水彩晕染、纸纹、线条抖动 |
| `src/paint.js` | 道具和环境：天空云朵、电线杆、麻雀、猫、七里香、雨、公交车等 |
| `src/people.js` | 两位主角：半身像、侧身骨骼、背影、剪影、握笔的手 |
| `src/scenes.js` | 32 个镜头的分镜与动画 |
| `src/lyrics.js` | 手写歌词排版（整句 / 关键词、自动换行、防出界）与涂鸦 |
| `studio.html` + `src/studio.js` | 歌词工坊界面 |
| `src/timing.js` | 歌词 / LRC 解析、套用节奏模板、打点与微调 |
| `src/export.js` | 浏览器内逐帧渲染 + WebCodecs 编码 + MP4 封装 |
| `src/template.js` | 参考录音的逐字时间骨架（仅数字） |
| `vendor/mp4-muxer.js` | MP4 封装库（MIT，见同目录 LICENSE） |
| `src/main.js` | 时间轴、转场（翻页 / 水彩晕开 / 铅笔涂抹 / 甩镜）、调色与后期 |
| `tools/align.py` | 人声分离 + 语音识别 + 拼音对齐，生成逐字时间轴 |
| `tools/render.mjs` | 用无头 Chromium 逐帧渲染，再用 ffmpeg 合成 MP4 |

## 命令行渲染

音频、歌词和字体**不在仓库里**，需要自己放进去：

```
input/song.mp3        歌曲音频
input/project.json    在歌词工坊里「保存工程」得到的文件（歌词、时间、样式）
```

或者不用工坊，直接用命令行自动对时：

```
input/lyrics.txt      每行一句歌词
input/keywords.json   可选，{"行号": "要写在屏幕上的关键词"}
input/settings.json   可选，{"mode": "lines" | "keywords", "position": "scene" | "bottom", ...}
```

```bash
# 网页字体子集已在 assets/fonts-web/（OFL，许可证在同目录）；想用完整 ttf 可运行 bash tools/fetch_fonts.sh
pip install sherpa-onnx soundfile librosa pypinyin
python tools/align.py              # 人声分离 + 语音识别，生成 input/timing.json 和 input/analysis.json
npm install
npm run render                     # 输出 out/七里香-MV.mp4（1920×1080，24fps）
```

常用参数：`--stills 30,95.5` 只出几张静帧，`--from 80 --to 96` 只渲染一段，`--workers 4` 并行进程数。

`bash tools/build_artifact.sh` 会把歌词工坊打包到 `build/artifact/`，方便发布成网页。
