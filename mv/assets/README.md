Put your own files here for auto-loading when the page is served over http(s):

- `song.mp3` (or `song.m4a` / `song.wav` / `song.ogg`)
- `lyrics.txt` (plain text or `.lrc`)

Everything in this folder except this README is git-ignored, so your audio and lyrics are never committed.
You can also just drag the files onto the page instead.
